FAHIM TAKRIM - AI GENERALIST PORTFOLIO
Latest revised site (version 2)

QUICK START
1. Extract this ZIP completely.
2. Open index.html in a modern browser.

For the most consistent local font and clipboard behavior, serve the extracted
folder over localhost. If Python is installed, run one of these commands inside
the folder containing index.html:

  Windows:       py -m http.server 8000
  macOS / Linux: python3 -m http.server 8000

Then open http://localhost:8000 in your browser.
Press Ctrl+C in the terminal to stop the server.

FILES
index.html         Page content and structure
style.css          Responsive layout, colors, and typography
app.js             Animations, cursor effects, headings, tabs, and controls
fonts/mono.woff    Included monospace font
fonts/LICENSE.txt Font license and attribution

EDITING
Edit index.html to change your introduction and section content.
Edit style.css to change the layout and styling.
Edit app.js to change the animation text, timing, and interactions.

HOSTING
This is a static website. No build step, package installation, API key,
server-side database, or external service is required. Upload index.html,
style.css, app.js, and the fonts folder together to any static website host,
preserving their relative paths. Deploy index.html at the site's root.

CONTROLS
Move the cursor across the opening word field to reveal block-and-dot trails.
The header includes motion pause/play and light/dark theme controls.
The introduction panel has its own playback control.
The exploration tabs support mouse, touch, and left/right arrow keys.
The site respects the browser's reduced-motion preference.

NOTES
The introduction panel is drawn in code; there is no separate video dependency.
The supplied reference screen recording is not required to run this site.
The copy-introduction control has a selectable-text fallback when clipboard
access is unavailable. There is no personal database or collected visitor data
included in this site.
